# rainfall-pattern-analysis
Analyze rainfall patterns across Indian cities with seasonal and categorical insights.

---

## 📌 Project Overview  
This is a **Power BI dashboard project** that analyzes rainfall distribution across Indian districts/cities using **historical monthly rainfall data**.  

It highlights the **seasonal contribution**, **monsoon share**, and **rainfall category distribution**, helping to understand rainfall intensity and regional variations.  

---

## 🔑 Key Insights  
- **Total Rainfall** → 67.69M mm (aggregated dataset)  
- **Monsoon Contribution** → 52.05M mm (~76.9% of total rainfall)  
- **Post-Monsoon Rainfall** → 5.9M mm  
- **Rainfall Categories** → Light, Moderate, Heavy, Very Heavy  
- **City/District Comparison** → Identifies wettest & driest regions  

---

## 🛠 Tools & Technologies  
- **Power BI Desktop**  
- **Data Source** → CSV/Excel (monthly rainfall data)  
- **Transformations** → Power Query Editor (season mapping, categorization)  
- **Visualizations** → Cards, Bar Charts, Donut Chart, KPIs  

---

## 🚀 How to Use  
1. Clone or download this repository.  
2. Open the `.pbix` file in **Power BI Desktop**.  
3. Connect/Refresh the data source (`india_monthly_rainfall_data.csv`).  
4. Explore interactive dashboards & insights.
